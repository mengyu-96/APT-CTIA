# APT归因研究核心思路总结

## 一、问题定义

**任务**：给定一个威胁情报报告，判断其属于哪个APT组织

**本质**：多分类文本分类问题

## 二、核心思路

### 思路1：基于文本特征的分类（推荐）

```
原始报告文本 
  ↓ 文本预处理（清洗、分词、去停用词）
  ↓ 特征提取（TF-IDF + N-gram）
  ↓ 特征向量化
  ↓ 机器学习分类器（RF/SVM/XGBoost）
  ↓ APT组织标签
```

**优点**：
- 实现简单，速度快
- 可解释性强（特征重要性）
- 适合小样本数据集

**关键技术**：
- **TF-IDF + 2-gram**：捕获关键词和短语特征
- **随机森林/XGBoost**：处理高维特征效果好
- **数据增强**：解决类别不平衡问题

### 思路2：基于深度学习的语义分类

```
原始报告文本 
  ↓ 预训练模型编码（BERT/RoBERTa）
  ↓ 语义向量表示
  ↓ 分类层
  ↓ APT组织标签
```

**优点**：
- 能捕获深层语义信息
- 对长文本效果好

**缺点**：
- 需要GPU资源
- 模型复杂度高
- 可解释性差

### 思路3：基于领域知识的特征工程

```
原始报告文本 
  ↓ 提取APT领域特征
    - MITRE ATT&CK技术
    - IOC（IP、域名、哈希）
    - 攻击工具名称
    - 目标行业、地理位置
  ↓ 传统特征 + 领域特征融合
  ↓ 分类器
  ↓ APT组织标签
```

**优点**：
- 结合领域知识，特征更专业
- 可解释性强

**缺点**：
- 需要构建领域知识库
- 特征提取复杂

## 三、推荐技术路线（快速实现）

### 第一阶段：基线实现（1-2周）

1. **数据加载**
   - 扫描数据集目录
   - 读取所有.txt文件
   - 按文件夹名称作为标签

2. **文本预处理**
   - 小写转换
   - 去除特殊字符
   - 分词、去停用词
   - 词干提取

3. **特征提取**
   - TF-IDF + 2-gram
   - 特征维度：5000-10000

4. **模型训练**
   - 随机森林（基线模型）
   - 数据划分：80%训练，20%测试

5. **评估**
   - 准确率、F1分数、混淆矩阵

### 第二阶段：性能提升（1-2周）

1. **数据增强**（解决类别不平衡）
   - CTGAN数据增强
   - 或SMOTE

2. **模型优化**
   - 尝试XGBoost、SVM
   - 超参数调优

3. **特征优化**
   - 特征选择（降低维度）
   - 尝试不同的N-gram组合

### 第三阶段：分析与改进（1周）

1. **错误分析**
   - 混淆矩阵分析
   - 识别容易混淆的APT组织对

2. **特征分析**
   - 特征重要性排序
   - 提取APT组织的特征词

3. **可视化**
   - 混淆矩阵热力图
   - 特征重要性柱状图

## 四、关键技术要点

### 1. 特征提取

**TF-IDF参数设置**：
- `ngram_range=(1, 2)`：同时用1-gram和2-gram
- `max_features=5000`：限制特征数量，避免过拟合
- `min_df=2`：过滤低频词（只出现1次的词）

### 2. 处理类别不平衡

**方法选择**：
- **CTGAN**：适合高维特征，效果好但慢
- **SMOTE**：速度快，适合低维特征
- **代价敏感学习**：调整类别权重

### 3. 模型选择

**推荐顺序**：
1. **随机森林**：快速、稳定、可解释
2. **XGBoost**：性能更好，但需要调参
3. **SVM**：高维数据效果好，但计算慢

### 4. 评估指标

**必须计算的指标**：
- **准确率（Accuracy）**：整体分类正确率
- **精确率（Precision）**：每个类别的精确率（宏平均）
- **召回率（Recall）**：每个类别的召回率（宏平均）
- **F1分数**：精确率和召回率的调和平均
- **AUC-ROC**：ROC曲线下面积（多分类用macro average）

## 七、常见问题

### Q1: 类别不平衡怎么办？
**A**: 使用数据增强（CTGAN或SMOTE）+ 代价敏感学习

### Q2: 特征维度太高怎么办？
**A**: 使用特征选择（如SelectKBest）+ 降维（PCA）

### Q3: 准确率不高怎么办？
**A**: 
1. 检查数据质量
2. 增加特征数量或改变特征提取方法
3. 尝试不同的分类器
4. 调整模型参数

### Q4: 某些类别分类效果差？
**A**: 
1. 检查该类别的样本数量
2. 检查是否有足够的特征区分度
3. 考虑专门针对该类别进行数据增强
