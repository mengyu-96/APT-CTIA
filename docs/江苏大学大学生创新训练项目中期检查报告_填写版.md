### （五）项目存在问题及解决方案

#### 1. 存在的问题

**（1）数据质量问题**
- **问题描述**：
  - 部分PDF报告是扫描件（图片格式），无法直接提取文本，导致数据丢失
  - 部分报告的实体提取不完整，可能影响图构建质量
  - 实体识别存在误识别和漏识别的情况

- **影响程度**：中等

- **解决方案**：
  1. 对于扫描件PDF，考虑使用OCR技术（如PaddleOCR、Tesseract）进行文本识别
  2. 完善实体提取规则，增加更多实体类型和匹配模式（如恶意软件名称、工具名称等）
  3. 建立实体词典（malware.json、tools.json等），提高实体识别准确率
  4. 对提取结果进行人工校验和修正，建立高质量的数据集
  5. 对于无法处理的报告，记录到skipped_reports.jsonl，后续单独处理

**（2）类别不平衡问题**
- **问题描述**：
  - 146个APT组织类别中，部分类别（如APT28、APT29）样本数量较多（50+），而部分类别样本数量很少（<5）
  - 存在严重的类别不平衡问题，可能影响模型训练效果

- **影响程度**：高

- **解决方案**：
  1. 使用类别权重平衡损失函数（加权交叉熵），给少数类别更高的权重
  2. 采用过采样技术（如SMOTE）或欠采样技术平衡数据集
  3. 合并相似的小类别（如"未知"、"多组织"等），减少类别数量
  4. 使用F1-macro、F1-weighted等更适合不平衡数据的评估指标
  5. 采用分层采样确保训练/验证/测试集中各类别比例一致

**（3）图结构稀疏性问题**
- **问题描述**：
  - 部分报告的图结构很稀疏（节点数<5，边数<20），可能影响模型学习
  - 小图的特征表示可能不够丰富

- **影响程度**：中等

- **解决方案**：
  1. 降低构图的最小实体数量阈值（当前为3），允许更多小图参与训练
  2. 添加虚拟连接或使用图增强技术（如添加自环、K-hop邻居连接等）
  3. 对小图使用特殊的处理策略（如特征增强、图级别特征等）
  4. 考虑使用图级别的统计特征作为补充（节点数、边数、密度、平均度等）
  5. 在训练时对小图进行数据增强（如添加噪声、边扰动等）

**（4）计算资源限制**
- **问题描述**：
  - 大规模模型训练（特别是GAT、Transformer）需要GPU资源
  - 本地计算资源有限，可能影响实验进度

- **影响程度**：中等

- **解决方案**：
  1. 使用云服务器（如AutoDL、阿里云、腾讯云等）进行训练，已申请相关经费
  2. 优化模型结构，减少参数量（如减少隐藏层维度、层数等）
  3. 使用混合精度训练（FP16），降低显存占用，提升训练速度
  4. 采用模型剪枝、量化等技术进一步优化
  5. 合理规划实验，优先进行关键实验，避免资源浪费

**（5）模型可解释性**
- **问题描述**：
  - 图神经网络模型的可解释性较差，难以理解模型决策过程
  - 难以向用户解释为什么某个报告被归因到某个APT组织

- **影响程度**：低（研究阶段，但实际应用时重要）

- **解决方案**：
  1. 使用GAT模型的注意力权重进行可视化，展示模型关注的节点
  2. 分析重要节点和边对分类结果的影响（如使用Grad-CAM等可解释性方法）
  3. 进行案例研究，深入分析典型样本的归因过程
  4. 生成归因报告，列出关键实体和关系作为归因依据

#### 2. 技术难点

**（1）实体关系提取**
- **难点**：如何准确提取实体之间的关系（如"使用"、"攻击"、"通信"、"目标"等语义关系）
- **当前状态**：目前主要使用共现关系（同一段落出现），语义关系提取较简单
- **解决思路**：
  1. 使用依存句法分析（如spaCy、Stanford NLP）提取语法关系
  2. 基于规则和模式匹配（如"X uses Y"、"X targets Y"等模式）
  3. 考虑使用关系抽取模型（如BERT-based关系抽取）
  4. 结合上下文信息判断关系类型

**（2）特征工程**
- **难点**：如何设计有效的节点特征表示，平衡语义信息和结构信息
- **当前状态**：使用类型one-hot + 哈希嵌入 + 统计特征
- **解决思路**：
  1. 结合文本嵌入（如BERT、Word2Vec）和统计特征
  2. 使用图结构特征（度中心性、PageRank、聚类系数等）
  3. 尝试不同的特征组合方式和维度
  4. 使用特征选择方法筛选重要特征

**（3）模型选择与调优**
- **难点**：如何选择最适合的GNN架构和超参数，避免过拟合
- **当前状态**：实现了多种模型，需要系统性对比实验
- **解决思路**：
  1. 进行系统性的对比实验（GCN vs GAT vs Transformer）
  2. 使用网格搜索或贝叶斯优化进行超参数调优
  3. 参考相关领域的最佳实践和论文
  4. 使用交叉验证评估模型性能

- **方法创新**：首次将图神经网络应用于APT归因任务，充分利用威胁情报报告中的结构化信息（实体、关系），相比传统文本分类方法具有明显优势
- **技术路线**：创新性地提出了从文本到图的知识图谱构建方法，将非结构化文本转换为结构化图数据，更适合捕获实体间的关系模式
- **多模型对比**：实现了多种GNN架构（GCN、GAT、Transformer、Hybrid），便于对比分析不同方法的优劣，为相关研究提供参考

### 2. 工程实践

- **完整系统**：从数据预处理到模型训练的全流程自动化系统，代码结构清晰，易于使用和维护
- **代码质量**：代码约2000行，注释完善，遵循良好的编程规范，具备良好的可维护性和可扩展性
- **文档完善**：提供了详细的使用文档（358行）和技术方案文档（652行），便于其他研究者理解和使用

### 3. 应用价值

- **实际应用**：方法可直接应用于威胁情报分析和APT攻击归因，为网络安全分析提供技术支持
- **可扩展性**：框架易于扩展，可支持新的实体类型、关系类型和模型架构
- **参考价值**：为相关研究提供了可复现的代码和实验框架，具有较高的参考价值
