# 终端中文乱码问题修复说明

## 问题原因

Windows PowerShell默认使用GBK编码（代码页936），而Python脚本输出使用UTF-8编码，导致中文显示乱码。

## 已实施的修复

### 1. Python脚本自动修复 ✅

已修改以下文件，自动设置UTF-8编码：
- `train_gnn.py` - 训练脚本
- `preprocess_apt_dataset.py` - 预处理脚本

**修复内容**：
- 在脚本开头检测Windows系统
- 自动将标准输出/错误输出设置为UTF-8编码
- 配置logging使用UTF-8编码

**效果**：运行这些脚本时，中文将自动正确显示，无需额外操作。

### 2. 辅助脚本

#### 方法1：使用批处理文件（推荐）
```bash
# 双击运行或在命令行执行
设置UTF-8编码.bat
```

#### 方法2：使用PowerShell脚本
```powershell
# 在PowerShell中执行
.\fix_encoding.ps1
```

#### 方法3：手动设置（临时）
```powershell

[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

## 技术细节

### 代码修改位置

**train_gnn.py** (第7-35行)：
```python
import sys
import io

# 设置标准输出编码为UTF-8
if sys.platform == 'win32':
    sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
    sys.stderr = io.TextIOWrapper(sys.stderr.buffer, encoding='utf-8')
```

**preprocess_apt_dataset.py** (第53-65行)：

### 编码说明

- **GBK (代码页936)**：Windows中文系统默认编码
- **UTF-8 (代码页65001)**：国际标准编码，支持所有字符
- **Python默认**：Python 3默认使用UTF-8编码

## 常见问题

### Q: 为什么修改了Python脚本还是有乱码？
A: 可能是终端编码未设置。先运行 `设置UTF-8编码.bat` 或执行 `chcp 65001`。

### Q: 能否永久设置？
A: 可以修改PowerShell配置文件，但建议使用Python脚本的自动修复功能，更灵活。

### Q: 其他Python脚本也有乱码怎么办？
A: 可以在其他脚本开头添加相同的编码设置代码。
