## 五、问题分析与建议

### 5.1 为什么准确率下降？

**可能原因**:
1. **图结构复杂度增加**: 平均边数从180增至925，模型需要学习更复杂的模式
2. **训练轮数不足**: 50个epoch可能不足以学习复杂的语义关系
3. **实体噪声**: 新实体类型（如USER_ACCOUNT、HOSTNAME）可能包含一些误匹配
4. **测试集扩大**: 从30个增至36个，统计更严格

**解决方案**:
1. ✅ 增加训练轮数（100-200 epochs）
2. ✅ 调整超参数（学习率、dropout、隐藏层维度）
3. ✅ 优化实体提取规则，减少误匹配
4. ✅ 使用更强的正则化（dropout、权重衰减）

### 5.2 如何进一步提升性能？

**短期优化**（1-2周）:
1. **超参数调优**
   ```bash
   # 尝试不同的配置
   --epochs 100 --lr 0.0005 --dropout 0.7 --hidden-dim 256
   ```

2. **实体提取优化**
   - 改进USER_ACCOUNT、HOSTNAME等模式的准确性
   - 添加实体过滤规则，去除明显误匹配

3. **图构建优化**
   - 调整语义关系边的权重
   - 优化边构建策略，避免过度连接

**中期优化**（1-2月）:
1. **特征工程**
   - 启用文本embedding（`--embed-text`）
   - 添加图级别统计特征
   - 使用预训练词向量

2. **模型架构**
   - 尝试不同的GNN架构（GraphSAGE、GIN等）
   - 使用异构图神经网络（支持多种边类型）
   - 添加注意力机制

3. **数据增强**
   - 图数据增强（边扰动、节点噪声）
   - 对少数类进行过采样
