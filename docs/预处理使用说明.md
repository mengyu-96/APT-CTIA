# APT归因数据集预处理使用说明

## 概述

`preprocess_apt_dataset.py` 是一个完整的数据预处理脚本，用于将APT威胁情报报告（PDF和TXT格式）转换为图神经网络（PyG）所需的格式。

## 功能特性

1. **自动扫描**：扫描 `dataset_PDF` 和 `dataset_TXT` 目录中的所有报告文件
2. **元数据提取**：从文件名自动提取APT组织、厂商、发布日期等信息
3. **文本提取**：
   - PDF文件：使用PyMuPDF提取文本（自动过滤页眉页脚）
   - TXT文件：自动检测编码并加载
4. **实体识别**：提取以下类型的实体：
   - IP地址
   - 域名
   - 邮箱地址
   - 文件哈希（MD5, SHA1, SHA256）
   - MITRE ATT&CK技术（T1055等）
   - CVE编号
   - 恶意软件名称（需提供词典）
   - 工具名称（需提供词典）
   - 组织名称（需提供词典）
   - 国家名称（需提供词典）
5. **图构建**：可选地将每份报告转换为PyG `Data` 图对象（节点=实体，边=段落共现）
6. **输出格式**：生成JSONL格式的段落和实体数据，并可直接导出 `graphs.pt`

## 安装依赖

```bash
pip install pymupdf chardet langdetect torch torch-geometric
```

## 使用方法

### 基本用法

```bash
python preprocess_apt_dataset.py \
    --pdf-root dataset_PDF \
    --txt-root dataset_TXT \
    --output-dir processed
```

### 完整参数

```bash
python preprocess_apt_dataset.py \
    --pdf-root dataset_PDF \
    --txt-root dataset_TXT \
    --output-dir processed \
    --vocabulary-dir vocab \
    --min-paragraph-length 20 \
    --feature-dim 64 \
    --min-entities 3
```

### 参数说明

- `--pdf-root`: PDF报告所在目录（必需）
- `--txt-root`: TXT报告所在目录（必需）
- `--output-dir`: 输出目录（必需）
- `--vocabulary-dir`: 可选，包含自定义词典的目录
  - `malware.json`: 恶意软件名称列表
  - `tools.json`: 工具名称列表
  - `organizations.json`: 组织名称列表
  - `countries.json`: 国家名称列表
- `--min-paragraph-length`: 段落最小字符数（默认20）
- `--keep-empty`: 保留空文档（默认会跳过）
- `--skip-graphs`: 只做文本预处理，跳过图构建
- `--min-entities`: 构图时报告内至少需要多少个实体（默认3）
- `--feature-dim`: 实体哈希特征维度（默认64）
- `--no-report-node`: 不在图中添加“报告根节点”与实体连接

## 输出文件

预处理完成后，在输出目录中会生成以下文件：

1. **raw_index.csv**: 报告元数据索引
   - `report_id`: 唯一报告ID
   - `apt_group`: APT组织名称
   - `source_vendor`: 报告来源厂商
   - `published_date`: 发布日期
   - `file_path`: 文件路径
   - `file_type`: 文件类型（pdf/txt）
   - `raw_name`: 原始文件名
   - `extra_tags`: 额外标签

2. **paragraphs.jsonl**: 段落数据（每行一个JSON对象）
   ```json
   {
     "report_id": "APT28_20231208_IBM_abc12345",
     "paragraph_index": 0,
     "language": "en",
     "text": "段落文本内容...",
     "apt_group": "APT28",
     "source_vendor": "IBM",
     "published_date": "2023-12-08",
     "file_path": "dataset_PDF/..."
   }
   ```

3. **entities.jsonl**: 实体数据（每行一个JSON对象）
   ```json
   {
     "report_id": "APT28_20231208_IBM_abc12345",
     "paragraph_index": 0,
     "label": "IP",
     "text": "192.168.1.1",
     "start": 123,
     "end": 133
   }
   ```

4. **skipped_reports.jsonl**: 跳过的报告（处理失败或空文档）

如未使用 `--skip-graphs`，还会生成：

5. **graphs.pt**：`torch.save` 的 `Data` 列表，每个元素对应一份报告图（节点=实体，边=段落共现/报告根连接）
6. **label_mapping.json**：APT组织到类别ID的映射表
7. **graph_stats.json**：每个图的节点、边数量统计，便于快速检查数据质量

## 自定义词典格式

如果需要使用自定义词典，创建JSON文件，格式如下：

**malware.json**:
```json
{
  "malware": ["BlackCoffee", "CozyDuke", "Lazarus", "Headlace"]
}
```

或简单列表格式：
```json
["BlackCoffee", "CozyDuke", "Lazarus", "Headlace"]
```

## 注意事项

1. **PDF处理**：如果PDF是扫描件（图片格式），将无法提取文本，会被标记为跳过
2. **编码检测**：TXT文件会自动检测编码，但可能不完美，建议使用UTF-8编码
3. **语言检测**：需要安装 `langdetect`，否则语言字段显示为 "unknown"
4. **性能**：处理大量文件可能需要较长时间，脚本会每10个文件输出一次进度

## 后续步骤

预处理完成后：
- 若开启了图构建，可直接 `torch.load('processed/graphs.pt')` 得到 `List[Data]` 并送入PyG模型
- 若仅生成了JSONL，可基于文件自定义图结构或做进一步特征工程

## 示例输出统计

处理完成后，脚本会输出：
- 发现的报告总数
- 成功处理的报告数
- 跳过的报告数
- 输出文件位置

# 图神经网络训练使用说明

## 概述

`train_gnn.py` 提供了完整的图神经网络训练流程，支持GCN、GAT、Transformer等多种模型架构，用于APT组织分类任务。

## 安装依赖

```bash
pip install torch torch-geometric scikit-learn
```

## 快速开始

### Windows用户

```bash
run_training.bat
```

### Linux/Mac用户

```bash
chmod +x run_training.sh
./run_training.sh
```

### 手动运行

```bash
python train_gnn.py \
    --graphs-path processed/graphs.pt \
    --label-mapping-path processed/label_mapping.json \
    --output-dir models/gnn_output \
    --model-type GAT \
    --hidden-dim 128 \
    --num-layers 2 \
    --heads 8 \
    --batch-size 32 \
    --epochs 100 \
    --lr 0.001 \
    --patience 20
```

## 参数说明

### 必需参数

- `--graphs-path`: 图数据文件路径（graphs.pt）
- `--label-mapping-path`: 标签映射文件路径（label_mapping.json）
- `--output-dir`: 输出目录（保存模型和结果）

### 模型参数

- `--model-type`: 模型类型，可选：
  - `GCN`: Graph Convolutional Network（简单快速）
  - `GAT`: Graph Attention Network（推荐，性能好）
  - `Transformer`: Graph Transformer（适合复杂关系）
  - `Hybrid`: 混合池化策略（mean + max pooling）
- `--hidden-dim`: 隐藏层维度（默认128）
- `--num-layers`: GNN层数（默认2）
- `--heads`: 注意力头数，仅用于GAT/Transformer（默认8）
- `--dropout`: Dropout率（默认0.6）

### 训练参数

- `--batch-size`: 批次大小（默认32）
- `--epochs`: 训练轮数（默认100）
- `--lr`: 学习率（默认0.001）
- `--weight-decay`: 权重衰减（默认5e-4）
- `--patience`: 早停耐心值（默认20）

### 数据划分

- `--train-ratio`: 训练集比例（默认0.7）
- `--val-ratio`: 验证集比例（默认0.15）
- `--test-ratio`: 测试集比例（默认0.15）

### 其他

- `--device`: 设备选择（auto/cpu/cuda，默认auto）

## 模型架构说明

### GCN (Graph Convolutional Network)
- **优点**：简单、快速、内存占用小
- **适用场景**：数据量大、需要快速训练
- **推荐参数**：`--num-layers 3 --hidden-dim 128`

### GAT (Graph Attention Network) ⭐推荐
- **优点**：性能好、可解释性强、能学习节点重要性
- **适用场景**：大多数情况下的首选
- **推荐参数**：`--num-layers 2 --heads 8 --hidden-dim 128`

### Transformer
- **优点**：能捕获复杂的关系模式
- **适用场景**：图结构复杂、关系多样
- **推荐参数**：`--num-layers 2 --heads 8 --hidden-dim 128`

### Hybrid
- **优点**：结合多种池化策略，可能提升性能
- **适用场景**：需要尝试不同池化策略时
- **推荐参数**：基于GAT，`--num-layers 2 --heads 8`

## 输出文件

训练完成后，在输出目录会生成：

1. **best_model.pt**: 最佳模型权重（验证集上表现最好）

## 性能优化建议

1. **GPU加速**：如果有GPU，会自动使用CUDA加速训练
2. **批次大小**：根据GPU内存调整 `--batch-size`（16/32/64）
3. **模型选择**：GAT通常性能最好，但GCN训练更快
4. **早停机制**：已内置，避免过拟合
5. **学习率调整**：已内置ReduceLROnPlateau，自动降低学习率

## 常见问题

### Q: 训练时显存不足？
A: 减小 `--batch-size` 或 `--hidden-dim`

### Q: 准确率很低？
A: 
- 检查数据质量（查看graph_stats.json）
- 尝试增加 `--num-layers` 或 `--hidden-dim`
- 尝试不同的模型类型（GAT通常更好）

### Q: 训练很慢？
A: 
- 使用GPU（`--device cuda`）
- 减小 `--batch-size` 或使用GCN模型
- 减少 `--num-layers` 或 `--heads`

### Q: 如何加载训练好的模型进行预测？
A: 
```python
import torch
from train_gnn import APTAttributionGAT

# 加载模型
model = APTAttributionGAT(input_dim=64, hidden_dim=128, num_classes=146)
model.load_state_dict(torch.load('models/gnn_output/gat/best_model.pt'))
model.eval()

# 预测
with torch.no_grad():
    output = model(graph.x, graph.edge_index, graph.batch)
    pred = output.argmax(dim=1)
```
